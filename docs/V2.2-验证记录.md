## 可以复核的演示

[v2.2-demo.json](v2.2-demo.json) 保存5段10轮交互的请求和响应，包含澄清、结果表、SQL、查询时间、引用和节点追踪。数据来自固定测试集，模型由确定性测试替身代替，因此只说明工程链路正确，不代表真实模型理解能力。

测试替身故意在最终模型消息中写入虚构的999999；服务最终展示只由真实数据库单元格生成，检查未出现该虚构数值。

## 真实模型评测状态

环境变量没有 DEEPSEEK_API_KEY，项目也没有 .env；本次未调用真实模型，不能声称准确率或P95提升。预检记录：[v2.2-evaluation-status.json](v2.2-evaluation-status.json)。

已准备：

- `python eval.py --mode all`：原30个单轮案例、执行等价性与引用一致性。
- `python eval_conversations.py --mode hybrid`：5段10轮对话，检查澄清、连续追问结果及引用。

引用一致性不代表SQL语义正确，仍需用参考查询验证。当前没有测量大规模多表召回或数据库租户RLS。

## 版本与启动

README、API标题、API version和MCP server version统一为 V2.2 / 2.2.0。需要安装新增依赖：`pip install -r requirements-dev.txt`。沿用V2.1索引，无需为V2.2重建业务表；会话表在独立SQLite文件中自动初始化。Compose新增sessions卷，并支持转发身份与会话配置。

默认是本地单用户模式；开启多用户会话隔离须设置API_CLIENT_KEYS。SQLite存储仅支持单API worker。
